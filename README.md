# VERDANT · 瓦片地图、动态河流与雨天实验

Godot 4.7 独立项目。打开 `project.godot`，打开主场景 `main.tscn`，按 F6 / F5；Mac 也可双击 `启动Demo.command`。默认晴天河流，角色为波风水门。

## 直接在主场景画地图

地图已经保存在 **main.tscn**，启动时不会随机生成，也不会覆盖瓦片。

1. 打开 `main.tscn`，选择 **Ground** 节点，在底部 **TileMap** 面板画地形。
2. 图集左侧四格为陆地色块；中间八格从深蓝到浅砂色，是由深到浅的河床；最右侧是树木。当前渲染器主要读取瓦片的自定义数据，陆地四格默认具有相同高度。
3. 河道中心使用深色河床瓦片，向两岸逐步换成浅色，最外侧接陆地。高度在相邻格子间平滑插值，让弯道和水位线连续。
4. 选择 **Trees** 节点，用最右侧的树木瓦片画树林。树木需画在 Ground 存在的格子上。
5. 保存场景再运行。地块数量和边界自动从 Ground 的已用区域读取，可以扩展地图，也可以擦除格子。

资源：`assets/tiles/river_tiles.svg` 是编辑器绘图用的瓦片图集，`river_tileset.tres` 定义 TileSet。每种瓦片有两项 Custom Data：

| 字段 | 用途 |
| --- | --- |
| `ground_level` | 地形投影高度，当前瓦片为 2 |
| `bed_height` | 归一化河床高度。陆地为 1.0，河床依次为 0.04、0.15、0.28、0.40、0.52、0.65、0.78、0.90 |

增加或修改瓦片时可以在 TileSet 编辑器修改这些值。主场景根节点 Inspector 还可设置 `River Enabled`、`Water Level`、`Flow Speed`、`Auto Tide`。

运行时隐藏原始 TileMapLayer 的静态绘制，读取其已保存的格子，用现有纯 2D 投影渲染器展示连续旋转。**TileMapLayer 是地图数据源，投影代码只负责显示，不生成地图布局。** 编辑器里的瓦片是地形类型示意，运行画面的河床纹理、植被和水面由渲染器处理。`Reload tiles` 重新读取当前运行实例的瓦片，不会自动读取磁盘中尚未重新加载的场景文件；普通编辑后请保存并重新运行。

## 动态水位河流

参考 [DEV LOG.03](https://www.bilibili.com/video/BV1KyjN6iEzq) 的视频画面与字幕：河床、水位遮罩、岸边高光、流动噪声和水下扰动。

`main.gd` 从 Ground 瓦片提取河床高度纹理。`shaders/river.gdshaderinc` 比较该高度与实时水位，决定露出的砂石和被水淹没的区域；同一套逻辑坐标用于噪声、岸线与倒影，旋转和缩放不会改变河道位置。

- 低水位露出更多河床，高水位淹没浅滩。
- 岸边细高光随水位移动，水流噪声推动波纹，河床细节发生折射式扰动。
- 雨天、落地水花、扩散涟漪、树木和水门倒影继续可用。
- CPU 按同样的插值规则计算水深。水深差不超过 0.12 的浅水可行走，更深的水阻挡角色；涨水淹过角色时将角色移到最近可用的安全地块。

这是二维视觉水位演示，没有求解流体体积、真实流速场或水面三维高度。河流没有真实质量守恒；河床凹陷主要是着色效果。水门没有游泳或涉水姿态。物体按地形→倒影→角色/树木的顺序合成，不适用于复杂高墙遮挡。地图很大时会增加 CPU 几何重建开销。

## 水门素材与动画

素材来自用户指定的 `black-sword/AI资源库/火影忍者/波风水门/sprite.png`。动画采用 `black-sword/scripts/actor_visual.gd` 的 OCAD 常量，**不是旧 npc.json 的 21×40 网格**。

- 21×42 精确区域；站立使用正面、背面、侧面各一帧。
- 行走每方向六帧、10 FPS；侧面素材朝左，向右时翻转。
- 沿用脚底锚点、树林遮挡和倒影；未接入战斗技能。

## 文件与预览

- `main.tscn`：持久化的地图、树林及主场景。
- `main.gd`：瓦片读取、投影、交互、角色和界面。
- `assets/tiles/`：可绘制的 TileSet 与图集。
- `shaders/river.gdshaderinc`：动态水位、河床和流动效果。
- `shaders/wet_world.gdshader`、`rain.gdshader`：雨天与倒影。
- `preview-river.png`：当前河流场景；旧预览图记录此前版本。

本次完成正常资源导入、静态审阅和画面预览，未运行自动化测试。旧版生成随机地图的检查入口已移除。

录制动态河流：

```bash
/Applications/Godot.app/Contents/MacOS/Godot --path . --write-movie /tmp/river.avi --fixed-fps 30 --quit-after 360 -- --river-film
```

此命令离线录制 12 秒自动涨落效果，录制帧率不代表实时性能。
