# VERDANT · 2D 等距视角旋转实验

独立 Godot 项目，参考 [《2D等距视角的视角旋转 DEV LOG.01》](https://www.bilibili.com/video/BV1x32vBREVZ) 的演示效果与视频中提到的「逻辑坐标 + 自制 Tilemap」思路。已查看视频抽帧和画面字幕；这里是独立实现，没有使用作者源码或提取视频里的美术资源。

## 启动

用 Godot 4.7 打开 `project.godot`，按 F6 或 F5。当前 Mac 也可直接双击 `启动Demo.command`。不需要下载素材、安装插件或连接网络。

## 操作

| 操作 | 输入 |
| --- | --- |
| 连续旋转 | Q / E，或鼠标右键拖动 |
| 自动旋转 / 暂停 | 空格或 Auto orbit 按钮 |
| 每次转 45° | 左侧角度按钮 |
| 平移焦点 | 鼠标左键 / 中键拖动，或 WASD |
| 缩放 | 鼠标滚轮 |
| 复位相机 | R |
| 像素坐标对齐 | P |
| 地块网格 | G |
| 树木显隐 | T |
| 生成另一组岛屿 | New islands |
| 切换地图大小 | 32 / 48 tiles（32×32 或 48×48） |

默认 32×32、1024 个地块，波风水门出生点附近会清出一小块空地；48×48 模式用于比较更大地图的绘制开销。面板实时显示地块数、可见数和帧率。

## 核心实现

逻辑位置 `p`、焦点 `focus`、旋转角 `angle`：

```text
r = rotate(p - focus, angle)
screen = origin + zoom * (r.x, 0.52 * r.y - height)
```

地形使用同一套坐标旋转投影，树木只投影根部位置，其图像始终在屏幕上直立。投影前的旋转坐标 Y 用于排序地块与树木。雨天版本按地形、倒影、直立树木三个批次绘制；树木之间按深度排序。拖动使用逆变换，所以转到任何角度都能沿屏幕方向平移。旋转轴始终是相机焦点。

水面、沙滩、草地、高地组成四个高度层，只生成面向相机且相邻地块更低的侧面。树木由代码生成三种像素精灵，和地形色块合并到同一张小图集。几何最终由 `CanvasItem.draw_mesh` 批量提交：这里的 ArrayMesh 只是承载二维三角形，没有使用 3D 场景或 3D 相机。相机及显示状态不变时复用几何，水面细节以低频更新。

`main.gd` 包含地形生成、投影、排序、批量绘制、交互和面板。`main.tscn` 是入口场景。

## 验证

在当前环境已用 Godot 4.7 通过：

```bash
/Applications/Godot.app/Contents/MacOS/Godot --headless --path . -- --verify
/Applications/Godot.app/Contents/MacOS/Godot --path . -- --sweep
```

- 固定种子的地形生成一致性、树木只生长在草地或高地。
- 五个角度下投影与逆投影一致、旋转焦点不漂移。
- 22 组角度与像素对齐模式实际绘制，无脚本或渲染错误。
- 自动旋转和相机复位。

生成默认截图：`Godot --path . -- --capture`，雨天默认输出 `preview-rain.png` 和 `preview-rain-detail.png`。`--sweep` 还会生成 `preview-135.png`。

## 范围与限制

这是演示旋转原理的渲染实验，不包含角色战斗、寻路或地图编辑器，也不是视频作者渲染系统的完整复刻。当前每次旋转都在 CPU 更新排序与几何，没有实现大世界分块、GPU 投影或性能基准系统；48×48 模式的连续旋转帧率会低于默认地图。界面帧率为当前机器的实测值，不代表跨设备性能保证。

像素对齐用于观察视频中提及的视觉伪影；它不会消除旋转时的像素跳动，当前没有加入模糊后处理。地形和树木采用简化的画家排序，适用于本例的低矮地形，不保证任意高墙、多层桥梁或交叉大型对象的遮挡正确。


## 雨天效果 · DEV LOG.02

参考 [《2D游戏中的雨天效果 DEV LOG.02》](https://www.bilibili.com/video/BV1s6rDBpEvo) 的画面与字幕实现，启动默认下雨。

- **H / Rain**：切换晴雨，湿润色调及积水逐渐淡出。
- **J / Puddles**：开关陆地积水；海面仍保留雨滴波纹。
- **K / Reflections**：单独开关树木倒影。
- **右上滑条**：调整雨量，影响雨丝密度、水花及涟漪数量和节奏。

`shaders/rain.gdshader` 绘制三层斜向下落的雨丝，使用不同速度、宽度和随机相位。天气层不遮挡操作面板，也不拦截鼠标。

`shaders/wet_world.gdshader` 把屏幕片元逆投影回逻辑世界，用固定世界坐标的多尺度噪声确定积水。改变角度、平移、缩放都不会使积水变成贴在屏幕上的遮罩。随机落点产生扩散圆环和短促的亮色水花，折射扰动作用于程序生成的地面细节。

树木反转绘制为倒影，再以同一个积水函数裁切；高度纹理额外保证倒影只出现在地图范围内、与树根同高度的表面。倒影 UV 随水波扭曲。环境偏冷、地表变暗与天空色共同表现雨天。

这里没有逐项照搬视频中的 SubViewport 管线：地面细节为程序纹理，倒影为镜像精灵；不是完整场景的反射/折射，也没有物理雨滴碰撞、角色踩水或雨声音效。雨丝与落地水花是独立的视觉层，不是一颗雨滴对应一次碰撞的模拟。为了合成倒影，使用地形→倒影→树木的简化顺序，不适用于高墙遮住树冠等复杂立体遮挡。

雨天回归检查：

```bash
/Applications/Godot.app/Contents/MacOS/Godot --path . -- --weather-test
```

覆盖两种地图尺寸、六个角度、天气/积水/倒影快捷键、干燥状态和相机参数同步。生成 `preview-clear.png`。此前曾生成固定 30 FPS、6 秒的离线演示录像，本仓库不包含该录像。


## 波风水门角色

使用用户指定目录中的 `sprite.png`，图像原样复制到 `assets/characters/minato.png`。动画依据 `black-sword/scenes/actors/player_minato.tscn` 的 `ocad_character` 模式和 `scripts/actor_visual.gd` 的 `OCAD_*` 常量转换，**不使用旧 npc.json 的规则网格配置**。站立为正面 (189,126)、侧面 (210,126)、背面 (231,126) 的单帧；各帧 21×42。行走前后朝向取 y=0/42、x=126…231 的六帧，侧面取 y=84、x=0…105 的六帧，10 FPS。侧面素材朝左，向右时水平翻转。显示比例适配本场景，脚底锚点与倒影按 42 像素帧高对齐。已移除本 demo 中此前的香香素材；源项目保持不变。

- **方向键**：沿屏幕方向移动水门。
- **F**：镜头回到水门。
- **WASD / 拖动**：移动镜头；滚轮缩放。

保留正面、背面、侧面动画、树林遮挡、雨天倒影，以及岸边和树干的简单阻挡。当前没有接入攻击技能。新地图生成时重新选取出生点并清出小片空地。

本次仅做正常资源导入、静态审阅和画面预览，没有运行自动化测试。`preview-minato.png` 为当前角色画面；其余预览截图记录此前的雨天和旋转效果，未更新角色。
